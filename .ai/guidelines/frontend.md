# Frontend y componentes React

- Después de modificar el frontend, ejecuta `pnpm run check:fix` y revisa las correcciones automáticas antes de finalizar.
- Crea componentes React funcionales. Define las props con `interface` cuando pueda expresar el contrato y usa `type` para contratos que requieran uniones u otras formas que una interfaz no exprese.
- Nombra las props con el nombre del componente seguido de `Props`, por ejemplo, `ButtonProps`.
